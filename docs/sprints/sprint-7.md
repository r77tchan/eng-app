## Sprint 7: 単語の音声再生（Web Speech API による TTS）

### 目的

英単語の発音を耳でも確認できるようにし、リスニング・スピーキング学習のきっかけを提供する。問題が切り替わったタイミングで自動的に英単語を発音し、ユーザーが任意のタイミングで再再生もできるようにする。静的ホスティング前提のため、事前録音音声ファイルは同梱せず、ブラウザ標準の Web Speech API（`speechSynthesis`）でクライアント側生成する。

### 前提

- Sprint 6 が完了していること（問題プール 120 問、「わからない」回答、セッション中断が動作していること）
- 既存 `lib/sound.ts`（正誤フィードバックの効果音）には触れず、音声再生は独立したモジュールとして実装すること

### 実装する機能

- **単語の自動読み上げ**: 学習セッションで新しい問題が表示されたタイミングで、英単語を自動で読み上げる
- **手動再再生ボタン**: 問題画面に再生ボタンを設置し、ユーザーがタップするとその時点の英単語が再生される
- **設定での ON/OFF**: 設定画面に「単語読み上げ」項目を追加し、ON/OFF を切り替えられる（既存「効果音」とは独立した別項目）
- **対応ブラウザ判定**: `speechSynthesis` が利用できない環境では、再生ボタンを表示せず、自動再生も行わない（クラッシュさせない）

### 設計判断（理由つき）

- **API 選択: Web Speech API（`speechSynthesis`）一択**
  - 理由 1: 静的ホスティング前提で、120 単語分の事前録音音声（mp3）を同梱すると容量が肥大し、新規追加時の JSON 整合性管理コストも高い
  - 理由 2: iOS Safari / Android Chrome の両方が対応しており、追加ライブラリ不要
  - 理由 3: 既存 `lib/sound.ts` の方針（"追加ファイルなし・basePath 解決不要・クライアント完結"）と完全に整合する
- **設定上「単語読み上げ」と「効果音」は別項目**
  - 理由: 効果音は正誤フィードバックの即時音、単語読み上げは学習対象の発音であり、ユーザーがオン／オフしたい動機が異なる（例: 周囲に人がいて効果音は切りたいが発音は聞きたい、あるいはイヤホン無しなので発音だけ切りたい）
- **自動再生はフィードバック後ではなく問題切り替わり時のみ**
  - 理由: フィードバック時に再生すると、ユーザーが「次へ」を押す直前に発音が被って煩わしい。学習目的（出題前に発音を聞いて推測する）と最も整合するのは「問題切り替わり時」
- **対応ブラウザでないときの挙動**
  - `speechSynthesis` が `undefined` または例外を投げる環境では、再生ボタン自体を非表示にし、自動再生もスキップする。設定画面の「単語読み上げ」項目は表示しつづけるが「お使いのブラウザでは利用できません」等の注記を出す
- **音声言語**: `en-US`（ロケール固定）
  - 理由: 既存問題プールの `word` は英単語であり、`en-US` 音声で発音させるのが自然。`en-GB` 等への切替は本スプリントでは対応しない（要望に無いため）
- **発話速度・音量**: ブラウザ既定値を使用（rate: 1.0、volume: 1.0）。ユーザー設定での調整は本スプリントでは対応しない
- **自動再生のタイミング**: 問題画面の `currentIndex` が変わって新しい問題がマウントされた直後。React 19 では `useEffect` body での同期 setState は禁止だが、`speechSynthesis.speak` は副作用なので問題なく useEffect 内で呼んで良い（state を変えない）
- **連打防止**: 再再生ボタンは連打されても問題ない（`speechSynthesis.cancel()` を呼んでから `speak()` し直す）

### スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### 音声再生機能

- [ ] 学習セッション画面に `data-testid="speak-button"` を持つ単語再生ボタンが表示される（`speechSynthesis` 利用可能環境のみ）
- [ ] 再生ボタンは問題文（英単語）の近くに配置されている
- [ ] 再生ボタンのタップ可能領域は **44×44px 以上**である
- [ ] 再生ボタンをタップすると、現在表示中の英単語が `speechSynthesis` で発話される
- [ ] 再生ボタンを連打しても音声が重ならない（前の発話がキャンセルされて新しい発話が始まる）
- [ ] 学習セッションで問題が切り替わると、設定が ON のときのみ英単語が自動で発話される
- [ ] フィードバック画面で「次へ」を押して新しい問題に切り替わったときも自動発話が動作する
- [ ] フィードバック表示中は自動発話されない（出題時点の 1 回のみ）
- [ ] `speechSynthesis` が利用できない環境（`window.speechSynthesis` が undefined、例外発生時）では、再生ボタンが描画されず、自動再生もスキップされ、アプリがクラッシュしない
- [ ] 発話の言語ロケールは `en-US` で固定されている（`SpeechSynthesisUtterance.lang = "en-US"`）

#### 設定との連動

- [ ] 設定画面に `data-testid="speech-toggle"` を持つ「単語読み上げ」項目があり、ON/OFF を切り替えられる
- [ ] 設定画面の「単語読み上げ」項目は「効果音」項目とは独立して並んでおり、表示順は「効果音」→「単語読み上げ」または同等の自然な並びである
- [ ] 「単語読み上げ」設定はリロード後も維持される（LocalStorage に永続化される）
- [ ] `Settings` 型に `speechEnabled: boolean` のような新規フィールドが追加され、既定値は `true`（音声機能を歓迎する向き）
- [ ] 既存の `Settings` LocalStorage に `speechEnabled` フィールドのないペイロードが残っていても、読み込み時にエラーにならず既定値で扱われる
- [ ] 「単語読み上げ」が OFF のときは、再生ボタンをタップしても発話されない（または再生ボタンが disabled / 非表示）
- [ ] 「単語読み上げ」が OFF のときは、問題切り替わり時に自動発話されない
- [ ] `speechSynthesis` 利用不可ブラウザでは、設定画面の「単語読み上げ」項目に「お使いのブラウザでは利用できません」等の注記が表示される、もしくは項目自体が無効化（disabled）される

#### 「効果音」との独立性

- [ ] 「効果音」を OFF にしても、「単語読み上げ」は ON のままなら問題切り替わり時に発話される
- [ ] 「単語読み上げ」を OFF にしても、「効果音」は ON のままなら解答時に正誤フィードバック音が鳴る
- [ ] 既存 `lib/sound.ts`（Web Audio API シンセサイズ）のコードは Sprint 7 で変更されない、もしくは変更があっても既存の効果音機能を壊さない
