## Sprint 5: 設定画面と PWA 化 + GitHub Pages デプロイ完成

### 目的

ユーザーがアプリの挙動をカスタマイズできる設定画面を提供する。あわせて PWA 化により通勤中アプリ利用のハードルを下げ、GitHub Pages 上で実際に公開できる状態まで仕上げる。本アプリは認証もクラウド同期も持たないため、設定値は全てブラウザストレージで完結する。

### 前提

- Sprint 4 が完了していること（JSON 問題プール拡張・カテゴリ難易度選択が動いていること）

### 実装する機能

- **設定画面**: 下部ナビゲーションに「設定」タブを追加し、専用画面を用意
- **既定カテゴリ・既定難易度**: 設定保存後はホームから直接セッション開始できる
- **テーマ切替**: ライト / ダーク（または自動）の切替
- **効果音 ON/OFF**: 正誤フィードバック時の効果音切替（音声ファイルは同梱）
- **データリセット**: 学習履歴・復習キュー・設定値のクリア
- **PWA 化**: Web App Manifest とアイコンを用意し、ホーム画面追加・スタンドアロン起動に対応
- **GitHub Pages デプロイ**: `output: 'export'` で生成された `out/` をデプロイし、公開 URL からアプリが動作する

### スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### 設定画面と下部ナビゲーション

- [ ] 画面下部ナビゲーションに「設定」タブが追加され、3 タブ（ホーム / 履歴 / 設定）構成になる
- [ ] 「設定」タブをタップすると設定画面に遷移する
- [ ] 設定画面に「既定カテゴリ」「既定難易度」の選択項目があり、変更が保存される（ブラウザストレージに永続化される）
- [ ] 既定カテゴリ・既定難易度の両方が設定済みの場合、ホームの「学習を始める」をタップすると選択画面をスキップして直接セッションが始まる
- [ ] 上記のスキップが有効な場合でも、選択画面を明示的に開く導線（例: 「カテゴリ/難易度を変えて始める」リンク）がホーム画面に用意されている

#### テーマ・効果音

- [ ] 設定画面に「テーマ」項目があり、少なくとも「ライト」「ダーク」の 2 値（または「システムに従う」を含む 3 値）から選択できる
- [ ] テーマを切り替えると即時にアプリ全体の配色が変わる
- [ ] テーマ設定はリロード後も維持される
- [ ] 設定画面に「効果音」項目があり、ON / OFF を切り替えられる
- [ ] 効果音 ON の状態で問題に解答すると、正誤に応じた効果音が再生される
- [ ] 効果音 OFF の状態では、解答時に一切音が鳴らない
- [ ] 効果音設定はリロード後も維持される

#### データリセット

- [ ] 設定画面に「学習データをリセット」ボタンが存在する
- [ ] 「学習データをリセット」ボタンをタップすると確認ダイアログが表示され、確認後に学習履歴・復習キューがクリアされる
- [ ] リセット後、ホーム画面の今日の学習問題数・正答率・ストリーク・復習が必要な問題数は全て初期値（0 件相当）に戻る

#### PWA

- [ ] アプリが Web App Manifest を持ち、ブラウザの「ホーム画面に追加」が利用可能
- [ ] PWA アプリアイコンが少なくとも 192x192px と 512x512px の 2 サイズ用意されている
- [ ] Manifest にアプリ名・短縮名・テーマカラー・背景色・`display: standalone` が設定されている
- [ ] ホーム画面に追加したアイコンからスタンドアロンモードでアプリが起動する（ブラウザのアドレスバーが表示されない）
- [ ] iOS Safari と Android Chrome の両方で、ホーム画面追加メニューが利用できる

#### GitHub Pages デプロイ

- [ ] `npm run build` で `output: 'export'` による静的書き出しが行われ、`out/` ディレクトリが生成される
- [ ] GitHub Actions などのワークフロー、もしくは README に記載された手順により、`out/` を GitHub Pages にデプロイできる
- [ ] 公開された URL（例: `https://<user>.github.io/<repo>/`）にアクセスすると、ホーム画面が正しく表示され、CSS・JS・JSON・アイコン等のアセットが 404 にならず読み込まれる
- [ ] 公開 URL 上でホーム → 学習セッション 5 問完走 → 結果画面 → ホーム復帰までの一連の操作が動作する
- [ ] 公開 URL 上で学習履歴・復習キュー・設定値が（同一ブラウザ内で）リロードを跨いで維持される
- [ ] GitHub Pages のサブパス配信下でも、内部リンク・アセット参照・JSON 取得パスが全て正しく解決される（`basePath` / `assetPrefix` が正しく機能している）

#### モバイル UI

- [ ] 375px 幅のビューポートで、設定画面の全項目が横スクロールなしで収まる
- [ ] 設定画面の操作項目（スイッチ・選択肢・ボタン）のタップ可能領域は最小 44x44px 以上である
