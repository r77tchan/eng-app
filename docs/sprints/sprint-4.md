## Sprint 4: 問題プール拡張（JSON）とカテゴリ・難易度選択

### 目的

学習体験のカスタマイズ性と継続可能性を高める。問題プールを JSON ファイルで拡張し、カテゴリ・難易度のメタデータを付与する。ユーザーが学習開始前に「何を学ぶか」を選べる動線を用意する。本アプリは静的サイトのため、JSON は全てリポジトリに同梱されたファイルとしてバンドルされる。

### 前提

- Sprint 3 が完了していること（復習キューが動いていること）

### 実装する機能

- **問題プールの拡張**: 同梱 JSON ファイルに 50 問以上の英単語 4 択問題を格納
- **カテゴリ・難易度メタデータ**: 各問題に「カテゴリ」と「難易度」を付与
- **カテゴリ・難易度選択画面**: 学習開始前にカテゴリと難易度を選べる画面
- **絞り込み出題**: 選択した条件に合致する問題のみがセッションに出題される
- **件数フォールバック**: 条件に合致する問題が不足する場合の出題ルールを定義

### スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### 問題データ

- [ ] 問題プールの JSON ファイルに少なくとも 50 問の英単語 4 択問題が格納されている
- [ ] 問題プールはリポジトリ内の JSON 静的ファイル（例: `/public/data/questions.json` または分割された複数 JSON）として管理されている
- [ ] 全ての問題に「カテゴリ」と「難易度」のメタデータが付与されている
- [ ] カテゴリは少なくとも 3 種類（例: 日常会話 / ビジネス / 旅行 など）、難易度は少なくとも 3 種類（初級 / 中級 / 上級）が定義されている
- [ ] 各カテゴリ・各難易度それぞれに少なくとも 5 問以上の問題が割り当てられている
- [ ] 問題データの取得は同梱 JSON のみから行われ、外部 API・クラウド DB へのアクセスは発生しない

#### カテゴリ・難易度選択画面

- [ ] ホーム画面の「学習を始める」ボタンをタップすると、カテゴリ・難易度選択画面に遷移する（既定値が未設定の場合）
- [ ] カテゴリ選択画面で「すべて」を含む少なくとも 4 つのカテゴリ選択肢が表示される
- [ ] 難易度選択画面で「すべて」を含む少なくとも 4 つの難易度選択肢が表示される
- [ ] カテゴリ・難易度はそれぞれ単一選択（または「すべて」を含む 1 値）として扱える
- [ ] 選択画面に「この設定で開始」ボタンがあり、タップすると選択した条件に合致する問題で学習セッションが開始される
- [ ] 選択画面にはホームに戻る導線が存在する

#### 絞り込みロジック

- [ ] 「すべて」以外のカテゴリ・難易度を選択した場合、そのセッションに出題される問題は全て選択条件に合致する
- [ ] 復習キューに含まれる問題のうち、選択した条件に合致するものは優先的に出題される
- [ ] 選択した条件に合致する問題数が 5 問未満の場合、画面に「条件に合う問題が不足しているため他の問題も出題されます」等の警告メッセージが表示され、不足分は条件外の問題で補充されて 5 問構成になる
- [ ] 1 セッション内で同じ問題が 2 回以上出題されない

#### モバイル UI

- [ ] 375px 幅のビューポートで、カテゴリ選択・難易度選択画面が横スクロールなしで収まる
- [ ] カテゴリ・難易度の選択肢のタップ可能領域は最小 44x44px 以上である
- [ ] 「この設定で開始」ボタンは画面下半分（親指リーチ範囲）に配置されている
