## Sprint 2: ローカル学習履歴とダッシュボード

### 目的

同一ブラウザ内で学習履歴を永続化し、ユーザーが「今日どれだけ学習したか」「連続何日学習しているか」を実感できる状態を作る。継続意欲を喚起するダッシュボードを実装する。本アプリには認証もクラウド同期も存在しないため、状態は全てブラウザストレージ内で完結する。

### 前提

- Sprint 1 が完了していること（学習サイクルが回ること、`output: 'export'` で静的書き出しできること）

### 実装する機能

- **学習履歴のローカル保存**: 各問題の解答結果（正誤・日時・問題 ID）をブラウザストレージ（LocalStorage または IndexedDB）に保存
- **ダッシュボード強化**: ホーム画面に「今日の学習問題数」「今日の正答率」「連続学習日数（ストリーク）」を表示
- **履歴画面**: 日別の学習問題数と正答率を一覧表示する新規画面
- **下部ナビゲーション**: ホーム / 履歴 を切り替える画面下部のタブバー

### スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### 永続化

- [ ] 学習セッションで問題に解答すると、解答内容（問題 ID・選んだ選択肢・正誤・解答日時）がブラウザストレージに保存される
- [ ] ブラウザをリロードしても保存された学習履歴が消えない
- [ ] 学習履歴の保存先はブラウザストレージ（LocalStorage / IndexedDB のいずれか）のみであり、外部 API・クラウド DB へは送信されない

#### ダッシュボード

- [ ] ホーム画面の上部に「今日の学習問題数」が数値で表示される
- [ ] ホーム画面の上部に「今日の正答率」がパーセント表示される（今日の解答が 0 問の場合は「-」または「0%」など明示的に表示される）
- [ ] ホーム画面の上部に「連続学習日数（ストリーク）」が「◯日」の形式で表示される
- [ ] ストリークは「1 日に 1 問以上正誤問わず解答した日」が連続している日数としてカウントされる
- [ ] 学習セッションを完了すると、ホーム画面に戻った時に上記 3 つの値が更新されている

#### ナビゲーション

- [ ] 画面下部に「ホーム」「履歴」の 2 つのタブを持つナビゲーションバーが表示される
- [ ] ナビゲーションバーは学習セッション中（問題を解いている画面）には表示されない（学習に集中できるようにするため）
- [ ] 「履歴」タブをタップすると履歴画面に遷移する
- [ ] ナビゲーションバーの現在のタブは視覚的にハイライトされている

#### 履歴画面

- [ ] 履歴画面には、過去に学習した日付ごとに「日付」「その日の問題数」「その日の正答率」がリスト表示される
- [ ] 履歴画面のリストは新しい日付が上に来る順序で並んでいる
- [ ] 学習履歴が 0 件の場合、履歴画面に「まだ学習履歴がありません」のような空状態メッセージが表示される

#### モバイル UI

- [ ] 375px 幅のビューポートで、ナビゲーションバーを含めた全要素が横スクロールなしで収まる
- [ ] 履歴画面の各行のタップ可能領域がある場合、最小 44x44px 以上である
