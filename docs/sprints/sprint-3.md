## Sprint 3: 復習システム（誤答キュー）

### 目的

「間違えた問題が自動で復習される」という学習効果の核となる機能を実装する。本アプリには認証もクラウド同期も存在しないため、復習キューもブラウザストレージで完結させる。旧計画にあった Supabase 認証・クラウド同期スプリントはアーキテクチャ方針変更により廃止された。

### 前提

- Sprint 2 が完了していること（ローカル学習履歴と履歴画面が動いていること）

### 実装する機能

- **誤答キュー**: ユーザーが誤答した問題 ID をブラウザストレージで「復習キュー」として管理
- **復習問題の優先出題**: 新規セッション開始時、復習キューにある問題が優先的に出題される
- **正答による復習キューからの除外**: 復習キュー内の問題に正答すると、復習キューから除外される
- **セッション結果に復習情報追加**: セッション結果画面で「復習に追加された問題数」「復習から卒業した問題数」を表示
- **ホーム画面の復習件数表示**: 復習が必要な問題数をダッシュボードに表示

### スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### 復習キュー管理

- [ ] 学習セッションで誤答した問題の ID が「復習キュー」としてブラウザストレージに保存される
- [ ] 復習キュー内の問題に正答すると、その問題 ID は復習キューから除外される
- [ ] 復習キュー内の問題に再度誤答した場合は、復習キューに残り続ける（重複登録はされない）
- [ ] ブラウザをリロードしても復習キューの内容は維持される
- [ ] 復習キューは外部 API・クラウド DB へ送信されず、ブラウザストレージ内でのみ管理される

#### 出題ロジック

- [ ] 復習キューが空の状態でセッションを開始すると、問題プールからランダムに 5 問が選ばれる
- [ ] 復習キューに 1 問以上 5 問未満の問題がある状態でセッションを開始すると、それらが全てそのセッションに含まれ、残りは問題プールから補充される
- [ ] 復習キューに 5 問以上溜まっている場合、新規セッションは復習キューから 5 問が出題される
- [ ] 1 セッション内で同じ問題が 2 回以上出題されない
- [ ] 問題プールに含まれない（例: 削除された）ID が復習キューに残っていても、エラーにならず無視される

#### UI フィードバック

- [ ] セッション結果画面で「今回の正答数」に加え「復習に追加: ◯問」「復習から卒業: ◯問」が表示される
- [ ] 「復習に追加」とは、そのセッションで初めて誤答してキューに入った問題数を指す
- [ ] 「復習から卒業」とは、そのセッション前から復習キューにあった問題のうち、今回正答してキューから除外された問題数を指す
- [ ] ホーム画面のダッシュボードに「復習が必要な問題数」が表示される
- [ ] 復習キューが 0 件の場合、ホーム画面には「復習: 0 問」のように 0 件であることが明示される

#### モバイル UI

- [ ] 375px 幅のビューポートで、結果画面の追加情報を含め全要素が横スクロールなしで収まる
- [ ] 復習に関する数値表示のフォントサイズ・コントラストは、揺れる車内でも読めるレベル（最低 `--text-base` 相当以上）で表示されている
