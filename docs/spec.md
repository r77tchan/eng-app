# CommuteEnglish（仮称） — 通勤中スマホ英語学習WEBアプリ

## 概要

通勤中の電車内など、1〜5分の隙間時間でスマホ片手で英語学習サイクルを完結できる WEB アプリ。短いセッション設計と片手操作 UI により、立ち姿勢・揺れる車内・短時間という制約下でも学習を継続できる体験を提供する。「机に向かう英語学習」ではなく「移動時間を英語学習時間に変える」ことを最大の価値とする。

本アプリは **完全にクライアントサイドで動作する静的サイト** として構築する。バックエンドサーバー・データベース・ユーザー認証は持たず、学習データはアプリに同梱した JSON ファイルから配信し、学習履歴等のユーザー状態はブラウザストレージにのみ保存する。

## ビジョン

通勤・通学の移動時間（往復で平均 60〜90 分）を、ストレスなく続けられる英語学習時間に変える。1 回の電車区間（最短 2〜3 分）で必ず 1 サイクルが完結し、達成感が得られる設計とする。

## ターゲットユーザー

### プライマリ

- 20〜40 代の社会人で、通勤に電車を使う日本人
- 英語学習を「したい意欲はあるが時間が確保できない」層
- 中学〜高校英語の語彙・文法を再学習したい層（いわゆる学習中級者まで）

### 利用シーン

- 電車内（立ち・座り両方）で片手にスマホを持っている状態
- イヤホン装着している場合もしていない場合もある
- 数駅区間（2〜10 分）の細切れ時間
- ホーム待ち時間、エスカレーター待ちなどの 30 秒〜1 分の超細切れ時間

## ユースケース

1. **隙間学習**: 改札を通った直後にアプリを開き、1 問だけ解いて電車に乗り、降りるまでに 5〜10 問解く
2. **継続確認**: 朝の通勤前に「今日のストリーク（連続学習日数）」を確認してモチベーション維持
3. **復習**: 過去に間違えた単語・フレーズが自動的に再出題される
4. **進捗確認**: 週末に 1 週間の学習量・正答率を眺めて達成感を得る

## アーキテクチャ前提（重要）

本アプリは GitHub Pages 等の **静的ホスティング** にデプロイすることを前提に設計する。下記の制約を満たすように全機能を実装する。

- **データベースを持たない**: クラウド DB・自前 DB ともに使用しない
- **認証機能を持たない**: ログイン機能・ユーザーアカウントは存在しない
- **学習データは JSON 静的ファイル**: 問題・単語・例文などはリポジトリ内の JSON ファイルとしてバンドルまたは `fetch` で取得する
- **ユーザー状態はブラウザストレージのみ**: 学習履歴・設定値・復習キューなどは LocalStorage / IndexedDB に保存
- **サーバーサイド機能を使わない**: Server Actions、動的 Route Handlers、middleware、ISR、画像最適化のデフォルトローダー等、サーバーが必要な機能は一切使用しない（Next.js の static export 制約に従う）

## 機能一覧

### 優先度: 高（MVP 必須）

- **クイック学習セッション**: 1 問あたり 10〜20 秒で回答できる 4 択問題（単語の意味選択）
- **セッション完結**: 5 問 1 セットで 1〜2 分以内に完結し、結果サマリーを表示
- **学習履歴のローカル保存**: 解いた問題・正誤・日時をブラウザストレージに永続化
- **片手操作 UI**: 親指リーチ範囲（画面下部）に主要タップ領域を配置
- **進捗ダッシュボード**: 今日の学習問題数・正答率・連続学習日数（ストリーク）を表示

### 優先度: 中

- **誤答問題の自動復習**: 誤答した問題が自動的に再出題キューに入る
- **問題プール拡張（JSON）**: バンドルされた JSON 問題ファイルから 50 問以上を読み込み（Sprint 6 で 120 問以上に拡張）
- **カテゴリ選択**: 例「日常会話 / ビジネス / 旅行 / 試験対策」などのカテゴリで絞り込み
- **難易度選択**: 初級 / 中級 / 上級
- **設定画面**: 既定カテゴリ・難易度、テーマ（ライト/ダーク）、効果音 ON/OFF、学習履歴リセット
- **「わからない」回答（Sprint 6 で追加）**: 4 択に加えて「わからない」を選べる第 5 の選択肢。誤答とは別カウントで履歴に記録され、復習キューに追加される
- **セッション中断（Sprint 6 で追加）**: 学習セッション中にホームへ戻れる中断ボタン。確認モーダル付き。中断時点までの解答は履歴・復習キューに反映される
- **単語の自動音声再生（Sprint 7 で追加）**: 問題が切り替わったタイミングで英単語を Web Speech API（TTS）で自動発音。ユーザーが再生ボタンを押して再再生もできる
- **PC キーボード操作対応（Sprint 8 で追加）**: 数字キー `1`〜`4` で選択肢を選ぶ、`Enter` で「次へ」、`Space` で「わからない」、`Escape` でセッション中断確認

### 優先度: 中

- **完全オフライン継続（Sprint 9 で実現済み）**: 設定画面の「オフライン用にダウンロード」を 1 回押すと、ビルド時に自動生成される `precache-manifest.json` に従って全ページ・全アセット (HTML / JS / CSS / フォント / 画像 / 音声 / JSON) を Service Worker で一括キャッシュする。以降は機内モードでも全ページに遷移でき、1 セッション (10 問) を完走できる。

### 優先度: 低

- **例文穴埋め問題**: 単語の意味だけでなく文脈での使い方
- **学習リマインダー（PWA 通知）**: 「今日まだ学習していません」

## 非機能要件

### モバイル最適化

- スマホ縦持ち（375px〜430px 幅）を第一優先のレイアウト基準とする
- タブレット・PC 幅でも崩れないが、最適化は行わない（モバイルファースト固定）
- すべての主要操作ボタンは画面下半分（親指リーチ範囲）に配置する
- タップターゲットは最小 44x44px を確保

### 片手操作性

- 1 問の回答に必要なタップ数は 1 タップ（4 択を直接タップ）
- 次の問題への遷移も 1 タップで完了
- スワイプ操作は補助のみ、必須機能には使わない（揺れる車内での誤操作防止）

### レスポンス速度

- 画面遷移は 500ms 以内
- 問題表示は端末起動から 3 秒以内に最初の問題が表示される
- 解答後の正誤フィードバックは即時（100ms 以内）

### オフライン対応

- 一度ロードした後はネットワークが切れても 1 セッションは完走できることを保証する（Sprint 5 で Service Worker による最小 pre-cache まで実装、Sprint 9 でワンボタン完全オフライン対応に拡張）
- **ワンボタン完全オフライン対応（Sprint 9 で実現済み）**: ユーザーが設定画面の「オフライン用にダウンロード」を 1 回押すと、ビルド時に自動生成される `precache-manifest.json` に従って全ページの HTML / JS / CSS / フォント / 画像 / JSON / 音声を一括キャッシュする。その後は機内モードでも未訪問ページを含むサイト全体に遷移でき、1 セッション (10 問) を完走できる。完了状態は LocalStorage (`commute-en:offline:v1`) に永続化され、次回起動時にも「オフライン対応済み」として復元される。設定画面から「キャッシュを削除」「再ダウンロード」も実行できる。

### データ永続化

- 学習履歴・復習キュー・設定値は同一ブラウザ内で永続化される
- 端末間同期は行わない（仕様外）
- ユーザーは設定画面から自分のデータをリセットできる

### ブラウザ対応

- iOS Safari（最新 2 バージョン）
- Android Chrome（最新 2 バージョン）
- PWA インストール可能であること（ホーム画面追加で起動できる）

### デプロイ

- GitHub Pages へのデプロイを前提とする
- Next.js の static export（`output: 'export'`）で `out/` ディレクトリを生成し、それを公開する
- リポジトリ名がパスに含まれる前提で `basePath` / `assetPrefix` を設定し、サブパス配信でもアセット・遷移が崩れないこと
- ルーティングは全てクライアントサイド遷移またはビルド時に静的生成されたページで完結する

## 想定する画面構成（モバイル前提）

1. **ホーム / ダッシュボード画面**
   - 今日の学習問題数、正答率、連続学習日数、復習が必要な問題数を上部に表示
   - 画面中央〜下部に大きな「学習を始める」ボタン
   - 下部にナビゲーション（ホーム / 履歴 / 設定）

2. **学習セッション画面（問題画面）**
   - 上部: 進捗インジケーター（5 問中の何問目か）
   - 上部右側: セッション中断ボタン（Sprint 6 で追加）
   - 中央: 問題文（英単語または英文）と音声再生ボタン（Sprint 7 で追加）
   - 下半分: 4 択ボタン（縦並び、各ボタン大きめ）
   - 下部: 「わからない」ボタン（Sprint 6 で追加、4 択の下に控えめに配置）

3. **解答フィードバック画面（同一画面内に重ねる想定）**
   - 正誤表示（◯ または ✕、色変化）
   - 正解と簡単な解説
   - 下部に「次へ」ボタン（親指リーチ）

4. **セッション結果画面**
   - 5 問中の正答数
   - 復習に追加された問題数 / 復習から卒業した問題数
   - 「もう 1 セット」「ホームに戻る」ボタン

5. **履歴画面**
   - 日別の学習問題数・正答率のリスト
   - ストリーク表示

6. **カテゴリ・難易度選択画面**
   - 学習開始前に絞り込み条件を選ぶ画面（既定値が設定済みの場合はスキップ可）

7. **設定画面**
   - 既定カテゴリ・既定難易度
   - テーマ（ライト/ダーク）
   - 効果音 ON / OFF（正誤フィードバック音）
   - 単語読み上げ ON / OFF（Sprint 7 で追加、効果音とは独立）
   - 学習履歴・復習キューのリセット
   - アプリバージョン表示

## 技術スタック推奨

- **フレームワーク**: Next.js（最新版・App Router）
  - `output: 'export'` による静的サイト生成
  - `node_modules/next/dist/docs/` の現行ドキュメントに従うこと（破壊的変更がある可能性があるため）
- **学習データ**: リポジトリ内の JSON ファイル（例: `/public/data/questions.json`）
- **ユーザー状態**: ブラウザストレージ（LocalStorage / IndexedDB）
- **スタイリング**: CSS Variables（`/docs/design-tokens.md` 準拠）+ Tailwind CSS（プロジェクト初期構成済み）
- **デプロイ**: GitHub Pages（静的ホスティング）

## 用語定義

- **セッション**: 5 問 1 セットの学習単位。1 セッションは 1〜2 分で完結する想定
- **ストリーク**: 連続して学習した日数。1 日に 1 問でも解答（「わからない」含む）すればカウントされる
- **問題プール**: 出題可能な問題の集合。アプリに同梱した JSON ファイルとして管理する
- **復習キュー**: 誤答した問題、および「わからない」と回答した問題のうち、まだ正答できていない問題の集合。ブラウザストレージで保持する
- **「わからない」回答（Sprint 6 で追加）**: 4 択のいずれも選ばずに「わからない」と意思表示する第 5 の選択肢。誤答とは別カウントで履歴に記録し、復習キューには追加される。学習行動としては成立しているのでストリーク・「今日の学習問題数」にはカウントされる
- **セッション中断（Sprint 6 で追加）**: ユーザーがセッション完了前にホーム画面に戻る操作。中断時点までの解答は履歴・復習キューに反映済みである（既に解答した問題のみ）。中断は履歴上「未完了セッション」として残らない（個々の解答ログのみが残る）
- **効果音 / 単語読み上げ**: 「効果音」は正誤フィードバック時に Web Audio API で生成される短い音。「単語読み上げ」は Sprint 7 で追加される、出題された英単語を Web Speech API で発音する機能。両者は設定上独立してオン／オフできる
